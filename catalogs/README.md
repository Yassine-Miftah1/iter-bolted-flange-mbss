# Catalogs

`helicoflex_HN200_SI.csv` — HELICOFLEX HN200 seal catalog converted to SI units (130 rows, `available` flag marks the seals compatible at 345 °C / 18.8 MPa).

Source: Technetics Group, *Metal Seals Master Catalog* (2020). Values were transcribed and converted for academic use; the original catalog is not redistributed here. Check the manufacturer's terms before keeping this file public.

Interpolation hypothesis for hot properties: piecewise-linear between 20 °C, θ_ref and θ_max (see report, Section 4).
